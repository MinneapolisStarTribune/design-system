# Drawer

Drawer is a modal panel attached to an edge of the viewport. Use it for supplementary work that
belongs next to the page rather than in the middle of it — filtering a list, reviewing details, or
editing settings for what's on screen. It slides in from the **left** or **right** as a
full-height panel, or rises from the **bottom** as a sheet.

`position` sets the edge at 768px and up; `mobilePosition` sets it at 767px and below. A filter
panel that sits on the right on desktop and becomes a bottom sheet on phones is
`position="right" mobilePosition="bottom"`. The switch is handled in CSS, so the same markup serves
both and nothing remounts when the viewport crosses the breakpoint.

**Web only.** It relies on portals and CSS media queries; native surfaces should use platform
modals.

## Anatomy

1. **Overlay** — Dims the page, blocks interaction underneath, and locks page scroll.
2. **Panel** — The surface: full height on the left or right edge, or a sheet on the bottom edge
   with rounded top corners.
3. **Close button** — Top-right dismiss control.
4. **Heading** — Names the drawer for assistive technology.
5. **Description (optional)** — One supporting line, announced with the heading.
6. **Body** — Main content. The only region that scrolls; its bottom edge fades out while more
   content sits below the fold.
7. **Footer (optional)** — Actions, sharing the row equally.

## Usage

- Give every drawer an accessible name: a `Drawer.Heading`, or `aria-label` when there is no
  visible title
- Keep `Drawer.Description` to one sentence; longer copy belongs in `Drawer.Body`
- Put the primary action **last** in `Drawer.Footer`, so it sits at the end of the row and last in
  tab order
- Close from your own controls with `useDrawerClose()`, from any component inside the drawer
- Set `closeButtonLabel` when "Close" alone is ambiguous, e.g. `"Close filters"`
- Leave drawers dismissable. Use `isDismissable={false}` only when deferring would lose the user's
  work — the close button still works, so keep it unless the footer offers another way out
- Don't nest drawers, and don't open one on page load

### Filter drawers

- Apply filters from an explicit footer action ("Show 999 Athletes") rather than on every change,
  so the page underneath doesn't reflow behind the overlay
- Put the result count in the primary button's label. It's announced when the user reaches the
  button; don't add a live region that announces every checkbox change
- Offer a "Clear All" action next to it

## Accessibility

- **Role and name** — The panel is a `role="dialog"` with `aria-modal="true"`, named by
  `Drawer.Heading` or `aria-label` and described by `Drawer.Description`. In development, a drawer
  with neither a heading nor `aria-label` logs a warning.
- **Focus on open** — Focus moves to the panel, so screen readers announce the drawer's name and
  description first. Pass `initialFocus` (a ref) to start somewhere else, such as a search field.
- **Focus trap** — Tab and Shift+Tab cycle within the drawer. Everything outside it is hidden from
  assistive technology and page scroll is locked.
- **Focus on close** — Focus returns to the trigger, or — when the drawer is opened from your own
  state — to whatever was focused when it opened.
- **Dismissal** — Escape and a press on the overlay close the drawer (unless `isDismissable` is
  `false`); the close button always does. There is no gesture-only way to dismiss.
- **Reflow** — Side drawers are capped at the viewport width and only the body scrolls, so content
  stays reachable at 320px wide and at 400% zoom.
- **Motion** — With `prefers-reduced-motion`, the drawer appears without sliding.
- **Forced colors** — The panel keeps a visible edge in Windows High Contrast, where shadows are
  dropped.

## Example

```tsx
const [open, setOpen] = useState(false);

<Button onClick={() => setOpen(true)}>Filter calendar</Button>

<Drawer
  open={open}
  onOpenChange={setOpen}
  position="right"
  mobilePosition="bottom"
  closeButtonLabel="Close filters"
>
  <Drawer.Heading>Filter Calendar</Drawer.Heading>

  <Drawer.Body>{/* filter groups */}</Drawer.Body>

  <Drawer.Footer>
    <UtilityButton label="Clear All" onClick={clearAll} />
    <Button color="brand" onClick={() => setOpen(false)}>
      Show {count} Athletes
    </Button>
  </Drawer.Footer>
</Drawer>
```
