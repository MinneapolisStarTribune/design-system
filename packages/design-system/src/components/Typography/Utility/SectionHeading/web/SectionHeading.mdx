# Section Heading

Section headings group related content within a page, providing a clear secondary level of hierarchy beneath the main page heading.
They help users scan and navigate complex layouts by visually separating functional areas or content groups.

- Use `importance` to control visual style.
- Use `as` when semantic heading level must differ from visual style.
- Example: `importance={3}` with `as="h2"` renders H3 typography on an H2 element.
