# TanStack Form

For form state and validation, use [TanStack Form](https://tanstack.com/form) with the adapters from `@minneapolisstartribune/design-system-tanstack-form` and a [zod](https://zod.dev) schema. See that package's README for every adapter and prop.

Pass the zod schema as a form validator and hand each `field` to an adapter. Schema issues map to fields by path, so each adapter shows its own error caption once the field is blurred or the form is submitted. No `createFormHook` setup needed.

### Multi-field

Initial value, required field with error, and format validation, all from one zod schema.

- **Name** — Optional; pre-filled with "Jane Doe".
- **Email** — Required; shows an error if empty or not a valid email.
- **Message** — Required; shows "Message is required" if left empty.
